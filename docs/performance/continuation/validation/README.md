The persistent UBSan diagnostic is a misaligned `stbir_uint64` store in the installed `stbimageheaders/include/stbimageheaders/stb_image_resize2.h:3735`, reproduced before and after this continuation. It is not suppressed or counted as a clean sanitizer pass. No package/dependency alignment fix is mixed into these equivalent-behavior phases. Windows, Linux, actual Emscripten, supported leak detection, forced allocation failures/interrupts and hardware counters have not been exercised.

The first full-suite launcher lacked the installed package namespace, so tests could not find internal helpers such as `sweep_mesh_data`. Its [failed harness log](release-harness-failed.log) is retained. Setting `package="rayvertex", load_package="installed"` fixes the launcher; the complete rerun passes without renderer changes. Focused tests use explicit exported/namespace-qualified helpers. The normal O2 threaded package was rebuilt after sanitizer/no-thread checks; [release build](build-final-release.log).

Reproduce from the repository root using `bash tools/validate-rasterizer-continuation.sh`. This script uses isolated libraries under `/tmp/rayvertex-optimization`, the recorded macOS sanitizer launchers, and `tools/test-rasterizer-package.R`. It runs strict focused sanitizer tests independently, records every process exit, retains recovering UBSan diagnostics separately, tests native no-thread fallback, then restores the normal release build. Inspect both status records and diagnostic logs. The baseline/scalar goldens are not regenerated by validation.

Measurement commands use `tools/bench-rasterizer-structural.py BEFORE_LIB AFTER_LIB OUTPUT` for the default/attribute phases and `tools/bench-rasterizer-structural-matrix.py BEFORE_LIB AFTER_LIB OUTPUT SUITE` for bins, macrotiles, coverage, geometry and quality sweeps. Prepared comparison sets `RAYVERTEX_PREPARED=1` for both libraries and `RAYVERTEX_STRUCTURAL_CASES=small,grid1m,shared_textures,environment`. The archiver reports preparation separately in this mode. Do not run benchmark processes alongside builds, tests or another benchmark.

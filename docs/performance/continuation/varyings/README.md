# Demand for common triangle attributes

`eec25f7`, compared with `dbaf8b1`, with all structural experiments disabled. [Full measurements](results.md) report ten workloads with cold/warm/native/sustained timings, phase medians/p95, R allocation and fresh-render RSS.

Frame-wide material/consumer unions now decide whether to allocate and populate UVs, view positions and shadow clip attributes. Texture channels, normal-mapped shader types and UV debug output retain UVs; point lights, Oren–Nayar, environment reflection/refraction, SSAO and position debug retain view positions; shadow maps retain clip storage. Main geometry setup returns the same projected vertices whether or not clip storage is needed. World normals stay allocated. Mixed materials conservatively retain a needed attribute for the entire frame; there is no new material remapping or changed interpolation arithmetic. Stable input validation remains active. `RAYVERTEX_REFERENCE_VARYINGS=1` restores the common arrays independently of debug output matrices.

For the generated 1,002,528-triangle grid, native varying payload falls 312,788,736 → 72,182,016 bytes. Fresh whole-process RSS falls 943.7 → 677.9 MiB; these measure different things. Native median is 216 → 176 ms, public median 276 → 240 ms, and sustained mean including cleanup is 291.2 → 249.4 ms. The separate diagnostic medians attribute the change to attribute/shader allocation (23.096 → 5.937 ms), main transform/setup (86.397 → 73.296 ms), coverage/shading (80.111 → 75.200 ms), and teardown (7.152 → 4.236 ms); bin build stays 9.514 → 9.512 ms. R allocations still include scene preparation and returned buffers. The optimization changes no sample quality.

Small-scene public median increases 22 → 23 ms and fresh RSS 199.8 → 204.2 MiB. SSAO native increases 107 → 110 ms while public is 153 → 150 ms; environment public is 77 → 78 ms. These short measurements do not establish stable tail latency or improvement for every scene. The default is justified by removal of provably unused storage and measured geometry/memory benefits, not by claiming universal speedups.

Validation has 96 assertions covering allocation/omission, all ordinary shader types, all texture channels, Oren–Nayar, mixed materials, lighting, debug returns and prepared/indexed parity. All 245 corrected-reference outputs and 44 additional shader/debug outputs match exactly with prepared assets and all new structural experiments enabled. The ten-workload measurement has 170/170 exact public image/debug-buffer comparisons. The additional 44-output corpus uses debug-all and therefore retains debug attributes; focused ordinary-output tests specifically exercise the demand path. [Logs](../varyings-validation/) retain the evidence.
